# @melodicbloom/mochi-ui

Claymorphism React components + deterministic spring physics from [Mochi UI](https://melodicbloom.github.io/mochi-ui/).

```bash
npm i @melodicbloom/mochi-ui motion react react-dom
```

```tsx
import { ClayButton, ClayCard, SpringPlayground, spring } from '@melodicbloom/mochi-ui';
import '@melodicbloom/mochi-ui/styles.css';
```

`spring` is the framework-neutral engine (`SpringValue`, `SpringRunner`, `MOCHI_SPRING_PRESETS`) bundled from `packages/spring-engine`.
